# Smartphone Price Analysis Dashboard

## 📊 Project Overview

This project analyzes smartphone prices and specifications using Power BI.

The dashboard provides insights into smartphone brands, RAM, storage,
price ranges and differences between websites.

## 🛠️ Tools Used

- Power BI
- DAX
- SQL
- Excel
- Power Query

## 📌 Key Analysis

- Average smartphone price by brand
- Highest-priced smartphones
- Price comparison by RAM
- Price comparison by storage
- Brand-wise price analysis

## 💡 Key Insights

Brand-wise Price Insight: Apple smartphones recorded the highest average price among the analyzed brands, while POCO recorded the lowest average price. This indicates that Apple is positioned toward the premium segment, whereas POCO focuses more on affordable/value-oriented smartphones.

Ram-wise Insight: Realme, Samsung, and Xiaomi provide a wider variety of smartphones across RAM categories.
